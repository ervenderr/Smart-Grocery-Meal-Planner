## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user restrictions -> swap filter | User free text drives filtering of safety-relevant suggestions |
| recipe ingredient name -> table lookup | Recipe text (user-authored or AI-generated) used as lookup key |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-09 | Information disclosure (safety) | Swap shown that conflicts with an allergy | mitigate | Remove (not grey out) conflicting swaps via both tag requirement and keyword violates check; hiddenCount reported; UI disclaimer; over-filter preferred to under-filter |
| T-09-10 | Denial of service | Long ingredient names or many restrictions | mitigate | canonicalName caps length; compileRestrictions caps 20 x 60 chars; token matching over a fixed ~200-key table |
| T-09-11 | Spoofing (wrong match) | Fuzzy match returns wrong ingredient | mitigate | No edit-distance matching; whole-token subset only, longest key wins, deterministic |
| T-09-SC | Tampering | package installs | accept | None |
