Pure reconciliation between the outbox and the React Query cache: re-apply pending ops over snapshots, patch with server results after apply, and roll back from stored inverses after park/discard.

Output: `frontend/lib/offline/reconcile/*` operating on plain data (no QueryClient), unit-tested.

Contracts THIS plan creates (11-11 hooks MUST write inverses in exactly these shapes):
- inverse.ts: InverseSchemas: per kind zod schema
    shopping.item.create: {}            -> rollback removes the item id
    shopping.item.update: { previous: Partial<ShoppingItem> }
    shopping.item.delete: { item: ShoppingItem }
    pantry.create: {}                   -> rollback removes the item id
    pantry.adjust: {}                   -> rollback subtracts payload.delta, clamped at 0
    pantry.update: { previous: Partial<PantryItem> }
    pantry.delete: { item: PantryItem }
    shopping.finish: {}                 -> rollback = no data change; caller refetches when online (list unlock is derived from outbox state)
    cook.apply: { previousCookedAt: string | null }
  parseInverse(op: OutboxOp): Inverse | null (null when invalid; caller then falls back to invalidate)
- type CacheWrites = ReadonlyArray<{ key: readonly unknown[]; update: (old: unknown) => unknown }>
- reapply.ts: reapplyForKey(key, data, ops: readonly OutboxOp[]): unknown  (dispatch by keyHash to fold functions for SHOPPING_ACTIVE_KEY, PANTRY_ALL_KEY, COOK_PANTRY_KEY, MEAL_PLANS_ALL_KEY; others unchanged; every op still present in the outbox is folded, including failed and blocked ones (rollback happens only on discard))
- apply-result.ts: applyResult(op: OutboxOp, result: unknown): CacheWrites  (shopping create/update -> upsertItem with server item; delete -> removeItem; pantry create/update/adjust -> replace the item by id with normalizePantryItem(server item) in PANTRY_ALL_KEY and COOK_PANTRY_KEY; pantry delete -> remove; unknown/invalid result -> empty writes)
- rollback.ts: rollbackOp(op: OutboxOp): CacheWrites  (per inverse rules above; returns empty writes when inverse invalid, plus a flag) -> signature rollbackOp(op): { writes: CacheWrites; needsRefetch: boolean }
</interfaces>
