<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API -> client (bootstrap pages) | Server JSON becomes persisted cache |
| SQLite -> React Query (hydrate) | On-disk rows (possibly stale/corrupt) feed UI state |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-09 | Denial of Service | hydrateAll | mitigate | zod envelope validation + per-row try/catch; invalid rows dropped and counted; never throws to the boot gate |
| T-11-10 | Information Disclosure | cache_entries cross-user | mitigate | user_id column; hydrate filters WHERE user_id = ?; null user hydrates nothing |
| T-11-11 | Information Disclosure | persisted AI/history data | mitigate | isPersistedKey whitelist with explicit deny for ai, cook preview, shopping history (tested) |
| T-11-12 | Tampering | bootstrap page | mitigate | zod validation per page; BootstrapError aborts without writing; maxPages guard prevents unbounded loops |
</threat_model>
