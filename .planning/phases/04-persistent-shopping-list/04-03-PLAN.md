## Phase Goal

**As a** Kitcha user shopping with my phone, **I want to** keep one saved shopping list that I can build by hand or from a meal plan, tick off in the aisle and close with what I actually spent, **so that** I buy what I need without losing the list or overspending.

<objective>
Contract layer between the list UI and the backend: rewrite the shopping types and API client to the endpoint set defined in research (and implemented by 04-01/04-04/04-06/04-08), add React Query keys, and add pure immutable cache-update helpers for optimistic mutations.

Purpose: SHOP-01/SHOP-02 client side. The current `lib/api/shopping.ts` and `types/shopping.types.ts` target `/shopping-lists` routes that never existed (multi-list shape, wrong `ShoppingItemCategory`).
Output: rewritten types, client, routes, query keys; list-cache helpers with tests.
</objective>
