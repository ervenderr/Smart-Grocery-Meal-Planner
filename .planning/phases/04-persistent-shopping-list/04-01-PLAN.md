## Phase Goal

**As a** Kitcha user shopping with my phone, **I want to** keep one saved shopping list that I can build by hand or from a meal plan, tick off in the aisle and close with what I actually spent, **so that** I buy what I need without losing the list or overspending.

<objective>
First vertical slice of the backend: the additive migration that guarantees one active list per user, the `shopping` module skeleton, and `GET /api/v1/shopping/list` that lazily creates and returns the user's persisted active list. Also defines every DTO/input contract and limit constant for the phase so later plans implement against them.

Purpose: SHOP-01 (lists stored in the backend, survive reload and device change). Race safety lives in the database, not in app code.
Output: migration, schema comment, shopping module (constants, types, dto, repository, service, controller, routes), route registration, integration tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> API | JWT-bearing requests; list identity must come from the token, never the client |
| API -> Postgres | raw SQL for the upsert primitive |
| deploy -> production DB | migration runs on existing data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information disclosure | GET /shopping/list | mitigate | List resolved only from `req.user.id`; no list id accepted; test that user B gets a different id |
| T-04-02 | Tampering | shopping.repository.ts raw SQL | mitigate | Tagged-template `$executeRaw`/`$queryRaw` only; grep gate forbids `*Unsafe` |
| T-04-03 | Tampering | duplicate active lists via races | mitigate | Partial unique index + `ON CONFLICT DO NOTHING` + `FOR UPDATE`; one bounded retry when a concurrent finish completes the locked row; 20-concurrent and retry tests |
| T-04-04 | Denial of service | migration on prod data | mitigate | Dedupe completes (never deletes) extras before the index; proven on TESTENV with seeded duplicates; `IF NOT EXISTS` |
| T-04-05 | Spoofing | all shopping routes | mitigate | `router.use(authenticate)` before any route; 401 test |
| T-04-06 | Information disclosure | error responses | accept | Existing errorHandler hides internals in production; no Prisma errors returned |
</threat_model>
