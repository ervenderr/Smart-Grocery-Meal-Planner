## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> DELETE /users/me | Destructive request carrying the user's password |
| deleted session -> next session in same tab | Residual client state |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-17 | Spoofing | delete with a stolen token | transfer | Server re-verifies password (plan 06); UI always sends it |
| T-07-18 | Information disclosure | stale cache after deletion | mitigate | clearAuth() runs resetUserSessionState + removes auth-token before router.replace |
| T-07-19 | Information disclosure | password lingering in state | mitigate | Password state cleared on close; input type=password with current-password autocomplete |
| T-07-20 | Denial of service | accidental deletion | mitigate | Password required, danger button never auto-focused, explicit irreversible copy |
</threat_model>
