| T-07-09 | Elevation of privilege | client consent bypass | transfer | Server-side requireAiConsent (plan 07) rejects with 403 regardless of client state |
| T-07-10 | Information disclosure | consent cached across accounts | mitigate | Consent lives in react-query (cleared by clearUserSessionState/clearAuth); zustand store holds only UI state, not persisted |
| T-07-11 | Information disclosure | data sent while state unknown | mitigate | decideAiAction('unknown') returns 'prompt' (unit tested), so no AI request fires before a known grant |
