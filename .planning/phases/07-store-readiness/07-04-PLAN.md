Backend contract (implemented by plan 07):
  POST /api/v1/ai/reports  (authenticated, NOT consent-gated)
    body: { kind: 'recipe' | 'meal_plan' | 'substitution',
            reason: 'inaccurate_or_unsafe' | 'offensive' | 'diet_or_allergy_mismatch' | 'other',
            note?: string (<= 500 chars),
            refId?: string (<= 100 chars),
            snapshot: object (JSON.stringify length <= 8192) }
    201 -> { id: string, createdAt: string }
    400 -> validation error; 401 -> unauthenticated
    429 -> { code: 'AI_REPORT_RATE_LIMITED', message: "You've sent several reports recently. Try again later." }
