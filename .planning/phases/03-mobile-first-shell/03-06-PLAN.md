## Phase Goal

**As a** Kitcha user standing in my kitchen or a grocery aisle with a phone, **I want to** install Kitcha and use every screen comfortably with one thumb, in my own currency, **so that** I can quickly see what I have, what to cook and what to buy.

<objective>
Make currency a real per-user setting end to end on the frontend: tested formatting helpers (Intl, no symbol tables), a preferences API module + React Query hook, a CurrencyProvider/useCurrency mounted app-wide, and the Settings currency picker with a numeric budget input. The dietary option list moves to a shared constant for onboarding (03-11).

Output: lib/currency/*, preferences API/hook/types, dietary constant, providers mount, rewritten preferences form.

Do NOT `git push`; plan 03-13 ships.
</objective>
