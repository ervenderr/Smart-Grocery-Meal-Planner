<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser (any origin) -> API | Cross-origin requests with Bearer JWT; Origin header is attacker-chosen for non-browser clients |
| Railway edge proxy -> API | Supplies X-Forwarded-For / X-Forwarded-Proto; leftmost XFF is client-controlled |
| Platform env -> process | Env values may be missing, weak or malformed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-08 | Spoofing | app.ts trust proxy + apiLimiter/authLimiter | mitigate | `trust proxy` = 1 (rightmost XFF), never `true`; trust-proxy.test.ts proves spoofed leftmost values share a bucket |
| T-01-09 | Information Disclosure | cors.config.ts predicate | mitigate | Exact allowlist plus a fully anchored preview regex that includes the owner scope `ervenderrs-projects`; tests reject kitcha-evil.vercel.app and other scopes |
| T-01-10 | Tampering | originGuard | mitigate | Disallowed Origin gets 403 before body parsing and routes, so simple cross-site POSTs do not execute side effects |
| T-01-11 | Information Disclosure | env.config.ts error output | mitigate | z.prettifyError prints paths and messages only; remove the old dump of env var names; test asserts secrets are absent from the message |
| T-01-12 | Elevation of Privilege | JWT_SECRET | mitigate | Zod enforces min 32 chars and rejects weak substrings; prod forbids `*`/localhost CORS |
| T-01-13 | Information Disclosure | /health | mitigate | Response limited to status/timestamp/uptime (no environment, no DB info) |
| T-01-14 | Denial of Service | /health exempt from limiter | accept | Handler is constant-time with no I/O; Railway probes it; abuse cost is negligible |
</threat_model>
