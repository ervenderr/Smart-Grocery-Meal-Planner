  <name>Native scan adapter, haptics wrapper, share builder</name>
  <files>frontend/lib/scan/scan-adapter.ts, frontend/lib/native/*.ts</files>
  <behavior>
    scan-adapter:
    - device.getInfo -> { isVirtual: true } => { kind: 'failure', failure: 'unavailable' } and scanner NOT called
    - scanner null (web/plugin missing) => failure 'unavailable'
    - device.getInfo rejecting => proceeds to scanner (do not block real devices on a Device plugin error)
    - ScanResult ' 4800016644801 ' => { kind: 'code', code: '4800016644801' } (normalized)
    - ScanResult '' or undefined => { kind: 'cancelled' } (A4: empty = cancel)
    - ScanResult 'hello' (not a valid barcode) => { kind: 'invalid' }
    - scanner rejects with message containing 'cancel' (any case) => cancelled
    - scanner rejects with message matching /denied|permission|not authorized/i => failure 'denied'
    - scanner rejects with any other error => cancelled is NOT used; returns failure 'busy' only if message matches /in use|busy/i, otherwise { kind: 'invalid' } so the UI shows NATIVE_SCAN_ERROR_COPY (no silent swallow of real errors)
    - options passed through unchanged to scanner
    haptics (fake clock, fake engine with vi.fn):
    - isNative false => engine never loaded, no calls
    - isEnabled false => no calls
    - 'light' -> impactLight, 'success' -> notifySuccess, 'warning' -> notifyWarning, 'selection' -> selection
    - two calls within 79 ms => second dropped; at 80 ms => fires
    - engine method rejecting => swallowed, logged message only; next call still works
    - loadEngine resolving null => no throw
    - haptic-prefs: missing key -> true; 'false' -> false; storage throwing -> true
    share builder:
    - only unchecked items included; header line per non-empty category using the group label; lines '[ ] Milk (2 L)' using unitLabel; quantity formatted without trailing zeros (1.5, 2)
    - categories in grouping order; count equals unchecked count
    - all items checked or empty list => count 0 and text 'Nothing left to buy.'
    - input not mutated
    shareList:
    - native true + canNativeShare true + nativeShare resolves => 'shared'
    - native true + nativeShare rejects with /cancel/i => 'cancelled'
    - native true + canNativeShare false => 'error'; native + other rejection => 'error'
    - native false + webShare present => 'shared'; webShare AbortError (name 'AbortError') => 'cancelled'
    - native false + no webShare + copy present => 'copied'; copy rejects => 'error'
  </behavior>
  <implementation>
scan-adapter.ts per contract. Per CONTEXT "plug into the existing scan sheet via an adapter, keep the Phase 6 resolution flow", outcomes map onto the existing CameraFailure union so `deriveView` in scan-sheet.tsx needs no new failure kinds. Pitfall 4: no transparent WebView, no html.scanning. Use isValidBarcode/normalizeBarcode from barcode.ts (do not re-implement).

haptics.ts per contract, closure `lastFiredAt` (number) replaced each fire; engine loaded once via memoized promise. Per UI-SPEC "no more than one haptic per 80ms". native-haptics.ts reads `@capacitor/haptics` definitions first to confirm `Haptics.impact({ style: ImpactStyle.Light })`, `Haptics.notification({ type: NotificationType.Success | Warning })`, and selection API (`selectionStart/selectionChanged/selectionEnd`; for 'selection' call selectionStart, selectionChanged, selectionEnd in sequence). It builds the engine via loadPlugin and the singleton via createHaptics({ isNative, isEnabled: () => readHapticsEnabled(window.localStorage access guarded), now: () => Date.now(), loadEngine }). Guard every window access for SSR.

share.ts per contract using groupItems and unitLabel. native-share.ts confirms `Share.canShare()` and `Share.share({ title, text, dialogTitle })` in the installed definitions, wires navigator.share (if function) and navigator.clipboard.writeText (if available), and returns the ShareOutcome; callers show toasts (plan 07) so this module does not import react-hot-toast.

Error logging everywhere: message only, never payload text.
  </implementation>
