## Pattern Assignments

### `frontend/next.config.ts` (config, transform)

**Analog:** itself (the whole file is 19 lines). Keep the release guard and branch only on the return value.

```typescript
const config = (phase: string): NextConfig => {
  if (phase === PHASE_PRODUCTION_BUILD && !process.env.NEXT_PUBLIC_API_URL) {
    throw new Error("NEXT_PUBLIC_API_URL must be set for production builds (e.g. https://<service>.up.railway.app)");
  }
  if (phase === PHASE_PRODUCTION_BUILD || phase === PHASE_PRODUCTION_SERVER) {
    logReleaseWarnings(process.env);
  }
  return {};   // <- replace with buildNextOptions(process.env) from lib/build/native-config.ts
};
```

Put the branch in a pure function `lib/build/native-config.ts` (`env.BUILD_TARGET === 'native' ? { output:'export', trailingSlash:true, images:{unoptimized:true} } : {}`), returning a fresh object (immutability). Test with vitest in the style of `lib/legal/legal-config.test.ts`. Web build must return `{}` (assert in test).

## Shared Patterns

### Dependency injection for testability
**Source:** `frontend/lib/api/session-refresh.ts`, `frontend/lib/scan/resolve-barcode.ts`
**Apply to:** token-store, scan-adapter, scheduler, haptics, share. Factory takes a `deps` interface; tests use `vi.fn()`.

### Error handling (log message only, never throw from storage/native wrappers)
**Source:** `frontend/lib/api/token-storage.ts`
```typescript
console.error('Token storage read failed:', error instanceof Error ? error.message : 'unknown');
return null;
```
**Apply to:** Keychain adapter, reminder scheduling, haptics, share (user-visible failures go through `react-hot-toast` with UI-SPEC copy).

### Safe storage access
**Source:** `frontend/lib/pwa/storage.ts` (`safeGetItem/safeSetItem` taking `StorageLike | undefined`; accessing `window.localStorage` itself can throw)
**Apply to:** first-launch marker (clear stale Keychain), reminder 14-day snooze, native boot scrub.

### Auth state access in hooks
**Source:** `frontend/lib/hooks/use-preferences.ts`
```typescript
const isAuthenticated = useAuthStore((s) => s.isAuthenticated);
return useQuery({ queryKey, queryFn, enabled: isAuthenticated, staleTime });
```
**Apply to:** any new data hook (reminders, pantry for scheduling).

### Test conventions
**Source:** `frontend/vitest.config.ts` (node env, `lib/**/*.test.ts`, `@` alias), `lib/pantry/expiry-tz.test.ts` (TZ matrix), `lib/api/session-refresh.test.ts` (setup helper). No jsdom or testing-library; do not add. `@vitest/coverage-v8` is not installed (planner decision).

### Immutability
`auth-store.ts` `updateUser` returns a spread copy (`{ ...state.user, ...user }`); token store snapshots must be replaced, never mutated.
