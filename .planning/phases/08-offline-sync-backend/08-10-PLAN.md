<objective>
Stop a 401 from wiping the user's local state: try a single-flight refresh first, retry the request once, and clear the session only on a definitive refusal from the refresh endpoint.

Purpose: SYNC-07, and the client half of SYNC-04 ("an expired access token is silently renewed"). This must ship before production lowers JWT_EXPIRES_IN to 1h.
Output: token storage helper, refresh coordinator + tests, interceptor wiring, auth store/forms/logout updates. Refresh token lives in localStorage on web (Keychain storage is Phase 10).
</objective>
