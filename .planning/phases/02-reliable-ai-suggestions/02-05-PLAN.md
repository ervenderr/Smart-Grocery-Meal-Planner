**As a** Kitcha user planning meals on my phone, **I want to** get recipe, meal-plan and substitution suggestions and product lookups that are always well-formed, respect my diet, and tell me clearly when AI is unavailable or I hit my daily limit, **so that** I can trust the suggestions without errors and without the app costing money.

Output: backend/src/modules/food/*, route registration in app.ts, tests (all upstream calls mocked; no network in CI).

| T-02-25 | Information disclosure | USDA key | mitigate | X-Api-Key header only, never URL or logs; test asserts key absent from response and logger calls |

| T-02-28 | Denial of service | lookup abuse by a user | mitigate | authenticate + global apiLimiter (100/15min/IP) + outbound throttle + cache |
| T-02-29 | Repudiation/licensing | attribution | mitigate | attribution object embedded in every success and not-found response |
