quantity.ts
- `export const D` = `Decimal.clone({ precision: 40, rounding: Decimal.ROUND_HALF_UP })`; `export type Dec = InstanceType<typeof D>`; `export const ZERO: Dec`.
- `export function toDec(value: number | string | Dec): Dec` (numbers go through `String(n)`; throws on non-finite).
- `export function parseDec(value: unknown): Dec | null` (finite number, numeric string, Prisma Decimal or Dec -> Dec; anything else -> null; never throws).
- `export function round2(d: Dec): Dec` (half up, 2 dp).
- `export function finalizeQuantity(d: Dec): number` (round2, clamp to [MIN_QUANTITY, MAX_QUANTITY], `.toNumber()`; only for positive inputs).

units.ts
- `export type UnitFamily = 'mass' | 'volume' | 'count'`; `export type UnitSystem = 'metric' | 'us'`.
- `export interface ResolvedUnit { readonly family: UnitFamily; readonly unitKey: string; readonly label: string; readonly factor: Dec | null; readonly system: UnitSystem | null }` where unitKey is the PantryUnit vocabulary key for mass/volume ('grams','kg','oz','lbs','ml','liters','tsp','tbsp','fl_oz','cups') or the normalized count key ('pieces' for piece/pieces/pc/pcs/item/items/empty; otherwise the lowercased, conservatively depluralized word such as 'clove', 'can'); label is the display text (PantryUnit key for mass/volume and 'pieces'; `coerceUnit(raw)` for free-text counts); factor is base units per 1 unit (grams for mass, ml for volume, null for count).
- `export function resolveUnit(raw: string | null | undefined): ResolvedUnit`.
- `export function familyKey(u: ResolvedUnit): string` -> 'mass' | 'volume' | `count:${unitKey}`.
- `export function toBase(qty: Dec, u: ResolvedUnit): Dec` (count: identity).
- `export function fromBase(base: Dec, unitKey: string): Dec`.
- `export function toDisplay(args: { family: UnitFamily; countLabel: string; baseTotal: Dec; inputUnitKeys: readonly string[] }): { unit: string; quantity: Dec }` (quantity is exact, NOT rounded; callers round once via finalizeQuantity).
</interfaces>
