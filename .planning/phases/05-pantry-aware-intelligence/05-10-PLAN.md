Backend contract from 05-08:
`GET /api/v1/recipes/cook-first?limit=1..200&today=YYYY-MM-DD&includeAll=true|false` -> 200 `{ items: Array<{ recipe: RecipeResponse; score: number; usesExpiring: Array<{ name: string; daysLeft: number }>; coveragePercent: number }>; expiringCount: number }`. Default limit 3. RecipeResponse matches the frontend `Recipe` type (name, category, difficulty, totalTimeMinutes, imageUrl, ingredients, ...).

Existing frontend:
- frontend/types/recipe.types.ts: `Recipe`, `RecipeFilters` (sortBy 'name' | 'prepTime' | 'cookTime' | 'totalTime' | 'createdAt'), `RecipesResponse`.
- frontend/lib/api/recipes.ts: `recipeApi.getAll(filters)`, `getStats`, `getById`, ... using `apiClient.get<T>(url)`.
- frontend/lib/pantry/expiry.ts: `formatExpiryLabel(days)` (reuse for "Expires today"/"2 days left" wording), local-date day math precedent.
- Dashboard page (298 lines): loads via useState + `Promise.all([...].catch(...))`; sections are `<Card className="min-w-0 p-4 sm:p-6">` with `<h2 className="mb-4 text-lg font-semibold text-gray-900">`; "Expiring Soon" card around line 250 uses `EmptyState` with `headingLevel="h3"`. Phase 4 lesson: a failing call must never crash the Home tab.
- Recipes page (319 lines): `fetchRecipes(activeFilters, search)` -> `recipeApi.getAll`; sort `<select value={filters.sortBy || 'createdAt'}>` with options createdAt/name/totalTime/prepTime/cookTime; renders `RecipeCard` grid.
- RecipeCard props: `{ recipe, onEdit, onDelete, onView }`.
- React Query is available (`useQuery`); query key factory in lib/react-query.ts is NOT modified by this plan (05-11 owns it); this plan defines its own key under ['recipes'] so recipe invalidations also refresh it.

Contracts this plan CREATES (frontend/lib/recipes/cook-first.ts):
- `export interface CookFirstEntry { recipe: Recipe; score: number; usesExpiring: { name: string; daysLeft: number }[]; coveragePercent: number }`; `export interface CookFirstResult { items: CookFirstEntry[]; expiringCount: number }`.
- `export const COOK_FIRST_QUERY_KEY = (today: string, limit: number, includeAll: boolean) => ['recipes', 'cook-first', today, limit, includeAll] as const`.
- `export function localDateString(now?: Date): string` (YYYY-MM-DD from LOCAL getters, never toISOString).
- `export function normalizeCookFirst(raw: unknown): CookFirstResult` (guards: non-object -> { items: [], expiringCount: 0 }; drops entries without recipe.id/name; usesExpiring filtered to {string name, finite integer daysLeft >= 0}; coveragePercent clamped 0-100).
- `export function expiringBadge(entry: CookFirstEntry): string | null` (null when usesExpiring empty; e.g. 'Uses spinach (1 day left)' or 'Uses spinach + 1 more expiring').
- `export function filterCookFirstEntries(entries, { search?, category?, difficulty? }): CookFirstEntry[]` (case-insensitive name search; preserves ranking order).
</interfaces>
