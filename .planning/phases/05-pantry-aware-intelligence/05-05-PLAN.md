Contracts this plan CREATES (05-07 and 05-09 code against these exact names):

merge-groups.ts
- `export interface IngredientLine { readonly name: string; readonly quantity: Dec; readonly unit: string; readonly source?: string }`
- `export interface IngredientGroup { readonly key: string; readonly canonical: string; readonly displayName: string; readonly family: UnitFamily; readonly countLabel: string; readonly baseTotal: Dec; readonly inputUnitKeys: readonly string[]; readonly sources: readonly string[] }` (countLabel = first-seen count label, '' for mass/volume; inputUnitKeys = distinct unitKeys in first-seen order; sources = distinct non-empty source strings in first-seen order; displayName = first-seen trimmed original name, whitespace-collapsed, never the canonical key).
- `export function groupKey(name: string, unit: string): string` = `canonicalName(name) + '\u0000' + familyKey(resolveUnit(unit))`.
- `export function groupIngredients(lines: readonly IngredientLine[]): IngredientGroup[]` (insertion order; skips lines with quantity <= 0 or empty canonical name; never mutates inputs).
- `export function displayOf(group: IngredientGroup): { quantity: Dec; unit: string }` (exact, via toDisplay; callers round once with finalizeQuantity).
- `export function withBaseTotal(group: IngredientGroup, baseTotal: Dec): IngredientGroup` (returns a new object).

pantry-subtract.ts
- `export interface PantryStockItem { readonly ingredientName: string; readonly quantity: unknown; readonly unit: string; readonly expiryDate: Date | null }` (quantity read via parseDec; Prisma Decimal, number or string accepted).
- `export type CoveredStatus = 'full' | 'partial' | 'incompatible'`
- `export interface CoveredEntry { readonly name: string; readonly needed: number; readonly have: number; readonly unit: string; readonly status: CoveredStatus; readonly haveUnit?: string }`
- `export function subtractPantry(groups: readonly IngredientGroup[], pantry: readonly PantryStockItem[], todayUtc: Date): { remaining: IngredientGroup[]; covered: CoveredEntry[] }`
