## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-09 | Denial of service | stapleNames payload | mitigate | `isArray({ max: 100 })` + per-item 1-60 chars with `bail`; existing body-size limit; canonicalName caps input at 200 chars |
| T-05-10 | Tampering | type confusion (non-string items, string instead of array) | mitigate | `isString().bail()` per element, `isArray` on the field; 400 VALIDATION_ERROR tests for 123, 'salt', '' |
| T-05-11 | Elevation / Information disclosure | per-user scoping | mitigate | Update keyed by `userId` from the JWT only; cross-user integration test |
| T-05-12 | Tampering | silent field drop (whitelist) | mitigate | Explicit `stapleNames: data.stapleNames` in the whitelist; GET-after-PATCH persistence test |
| T-05-13 | Denial of service | migration on prod data | mitigate | Additive ADD COLUMN with DEFAULT only (no UPDATE/DELETE), proven on TESTENV with a pre-existing row; drift check exit 0 |
| T-05-14 | Tampering / XSS | staple strings rendered later | mitigate | canonicalName strips punctuation/markup characters to letters, digits and spaces before storage |
