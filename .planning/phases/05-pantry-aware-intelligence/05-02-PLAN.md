Existing in backend/src/modules/analytics/analytics.service.ts (597 lines):
- `private getPeriodKey(date: Date, period: string): string` (around line 514). It is called for `item.purchaseDate` (price trends, ~line 317) and `item.receiptDate` (spending trends, ~line 495). The daily branch uses `date.toISOString().split('T')[0]`; weekly uses `date.getFullYear()` + `this.getWeekNumber(date)`; monthly uses local `getFullYear()/getMonth()`.
- `private getWeekNumber(date: Date): number` (around line 531) builds from local getters.

Contract this plan CREATES:
- `export function isoWeekKey(date: Date): string` -> `YYYY-Www` using the ISO week-year and UTC getters.
- `export function periodKey(date: Date, period: string): string` -> 'daily': `YYYY-MM-DD` (UTC); 'weekly': isoWeekKey; anything else: `YYYY-MM` (UTC).
