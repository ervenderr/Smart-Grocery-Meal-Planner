## Phase Goal

ROADMAP goal (verbatim): Generated shopping lists contain only what the user actually needs to buy, and the app shows what to cook before food expires.

<objective>
Wire the intelligence engine into `POST /api/v1/shopping/generate`: aggregate the plan exactly, drop staples, subtract non-expired pantry stock, merge the remainder into the active list with unit-aware updates, and return the additive response `{list, added, merged, covered, skippedStaples}`. Preserve every Phase 4 lock/cap/transaction rule.

Purpose: INT-03 (subtract pantry), INT-04 (staples excluded) and the persisted half of INT-02 (converted units stored).
Output: unit-aware bulk update, rewritten generate service, extended response type, updated Phase 4 integration tests, new intelligence-generate integration tests.
</objective>
