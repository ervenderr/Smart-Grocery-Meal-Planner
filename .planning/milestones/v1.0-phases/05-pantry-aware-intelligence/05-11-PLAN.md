Backend contract from 05-09: `POST /api/v1/shopping/generate` -> `{ list, added, merged, covered: Array<{ name: string; needed: number; have: number; unit: string; status: 'full' | 'partial' | 'incompatible'; haveUnit?: string }>, skippedStaples: string[] }`. - frontend/lib/auth/session-cleanup.ts clears the whole QueryClient cache on logout/user switch (so a key under ['shopping'] is cleared too; verify).
- frontend/lib/shopping/vocab.ts: `unitLabel(value)` for display units.
- Shopping page (259 lines) renders `<QuickAdd ... />` then `<GenerateFromPlan defaultExpanded={items.length === 0} />` when not in shopping mode.
- Meal Plans page (250 lines): preview Card with 'Add to my list' Button (`generateList.mutate(selectedPreviewPlan.id)`) and 'Open list' Button shown when `generateList.isSuccess && generateList.variables === selectedPreviewPlan.id`.
- Disclosure precedent: components/shopping/generate-from-plan.tsx (h2 > button with aria-expanded/aria-controls, ChevronDown rotate, min-h-11).

Contracts this plan CREATES:
- types: `export interface CoveredItem { name: string; needed: number; have: number; unit: string; status: 'full' | 'partial' | 'incompatible'; haveUnit?: string }`; `GenerateShoppingListResult` gains `covered?: CoveredItem[]; skippedStaples?: string[]; pantryCapped?: boolean`.
- covered-note.ts: `export interface LastGenerateResult { mealPlanId: string; added: number; merged: number; covered: CoveredItem[]; skippedStaples: string[]; pantryCapped: boolean }`; `export function toLastGenerateResult(mealPlanId: string, result: GenerateShoppingListResult): LastGenerateResult` (missing/invalid arrays -> []); `export function formatCoveredLine(item: CoveredItem): string`; `export function buildGenerateNotes(last: LastGenerateResult | null | undefined): { coveredLines: string[]; skippedText: string | null; cappedText: string | null; hasNotes: boolean }` (cappedText = 'Your pantry is too large to fully compare; some items may already be in your pantry.' when pantryCapped).
- react-query.ts: `queryKeys.shopping.lastGenerate: () => ['shopping', 'last-generate'] as const`.
- describeGenerateResult accepts `{ added; merged; covered?; skippedStaples? }`.
