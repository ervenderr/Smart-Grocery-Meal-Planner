## Phase Goal

**As a** Kitcha user shopping with my phone, **I want to** keep one saved shopping list that I can build by hand or from a meal plan, tick off in the aisle and close with what I actually spent, **so that** I buy what I need without losing the list or overspending.

<objective>
Backend slice for manual list editing: item create/update/delete endpoints with strict validation, ownership on every id, the 300-item cap under the list row lock, server-side `inferCategory`, and a dedicated shopping rate limiter that the global limiter skips.

Purpose: SHOP-02 (add, edit, remove, check off; persisted) and the category half of SHOP-04.
Output: category helper, validation, item service/controller/routes, limiter, tests.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-13 | Information disclosure / Tampering (IDOR) | PATCH/DELETE /items/:itemId | mitigate | Lock the user's active list first, then scoped `findFirst` (`shoppingListId` = locked list, `shoppingList: { userId, isCompleted: false, deletedAt: null }`) before any write; P2025 mapped to 404; identical 404 for unknown/foreign/completed/already-deleted; cross-user, delete-twice and edit-after-finish tests |
| T-04-13b | Tampering | free-text unit | mitigate | `normalizeUnit` allow-list pattern (letters, digits, space, . % / -), max 20 chars, same rule on POST and PATCH; React escapes on render |
| T-04-14 | Elevation of privilege (mass assignment) | POST/PATCH bodies | mitigate | `matchedData` + explicit 8-field whitelist; test that shoppingListId/userId in body are ignored |
| T-04-15 | Denial of service | item growth, huge numbers | mitigate | 300-item cap checked under `FOR UPDATE` lock; name 100, notes 500, qty 0.01..99999, cents 0..200,000,000; 1 MB body limit already in app.ts |
| T-04-16 | Tampering (stored XSS) | itemName/notes | mitigate | Store trimmed plain text with control chars stripped; React escapes on render; no `escape()` (avoids corrupting "&") |
| T-04-17 | Denial of service | rate limiting | mitigate | Per-user shoppingLimiter 600/15min with JSON 429; global limiter skip limited to the exact /api/v1/shopping prefix regex |
| T-04-18 | Tampering (race to exceed cap) | concurrent POSTs | mitigate | Count + insert inside one transaction holding the list row lock |
