## Phase Goal

**As a** Kitcha user shopping with my phone, **I want to** keep one saved shopping list that I can build by hand or from a meal plan, tick off in the aisle and close with what I actually spent, **so that** I buy what I need without losing the list or overspending.

<objective>
Frontend slice that makes the persisted list usable: React Query hooks with optimistic check-off, quick-add row, item rows grouped into collapsible category sections, the edit sheet with delete + undo, and a rewritten Shopping page replacing the sessionStorage list.

Purpose: SHOP-01 (visible persistence), SHOP-02 (manual add/edit/remove/check), SHOP-04 (category grouping).
Output: one hook module, four components, rewritten page.
</objective>
