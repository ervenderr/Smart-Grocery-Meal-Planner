| Boundary | Description |
|----------|-------------|
| public internet -> /manifest.webmanifest and icons | unauthenticated static assets |
| browser storage -> hint | localStorage may be unavailable or tampered |
| build machine -> committed PNGs | generated binaries enter the repo |

| T-03-39 | Denial of service | localStorage in Safari private mode | mitigate | all access through safeGetItem/safeSetItem try/catch, including obtaining window.localStorage; unit tests with throwing stubs |
| T-03-40 | Tampering | localStorage value | accept | only controls a cosmetic hint; any value other than '1' just shows the hint |
