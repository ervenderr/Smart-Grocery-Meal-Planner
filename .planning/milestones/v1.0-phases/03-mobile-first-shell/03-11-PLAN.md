## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user input -> pantry create / preferences update | item names, budget, currency, dietary values cross to the API |
| API response -> gate | preferences shape may come from an older backend |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-33 | Tampering | item names | mitigate | trimmed, length-capped (100) client-side; backend pantry validation authoritative; React escaping in pills |
| T-03-34 | Tampering | currency/dietary values | mitigate | picker limited to SUPPORTED_CURRENCIES and DIETARY_OPTIONS; backend isIn allow-list |
| T-03-35 | Denial of service | onboarding blocking the app | mitigate | fail open on error/missing field (unit-tested); Skip setup always available |
| T-03-36 | Tampering | duplicate pantry rows on retry | mitigate | createdNames tracking makes finish retry idempotent; server completion endpoint idempotent (03-02) |
| T-03-37 | Elevation of privilege | completion for another user | mitigate | endpoint uses the bearer token's user only (03-02); no id sent |
</threat_model>
