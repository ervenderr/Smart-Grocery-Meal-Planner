## Phase Goal

ROADMAP goal (verbatim): The pantry stays accurate with minimal typing as users scan, shop and cook.

<objective>
Vertical slice, API half of "Bought it" (CAP-03): `POST /shopping/finish` accepts `addToPantry` and, after the finish transaction commits, merges or creates pantry items from the checked list items. The finish-sheet toggle ships in 06-07.

Purpose: CONTEXT "Bought-it merge: merge into an existing non-expired pantry item with the same canonical name and unit family (Phase 5 helpers); otherwise create a new item with category from inferCategory, purchase date and price from the list item." Resolved decision: runs after the finish transaction commits in its own try/catch (never rolls back the finish); response carries `{added, merged, failed}`; units coerced through resolveUnit to the closed PantryUnit list.
Output: pure merge planner + service + finish extension + tests.
</objective>
