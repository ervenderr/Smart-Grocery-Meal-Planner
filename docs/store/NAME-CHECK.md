# App Name Check

## Status

Working name: **Kitcha (not cleared)**. Code and assets keep the working name in this phase.

This is not a trademark clearance or legal advice; the owner decides (human gate). Code is not renamed in this phase.

## Known conflict

"Kitcha: Save, Plan, Cook" by Kamp Inc (kitcha.io, App Store ID 6758049420, Android package io.kitcha.app) is an existing iOS/Android app in the same category doing the same job (recipe saver, meal planner, shared grocery list). Source: `.planning/research-v2/04-monetization-appstore.md` (secondhand listings; needs owner verification on the live stores).

App Store names must be unique, and an identical name in the same category invites a trademark/IP complaint (Guideline 5.2).
